In this tutorial, we use scBaseCount to create an atlas of embryonic data across 5 species, and label the cell types with their closest match from the HUman Fetal Atlas to create a cross-species map of embryonic development.

In seperate scripts, this we assemble the embryo data from across scBaseCount, embed it using transcriptformer, map cell types from the Human Fetal Atlas, and analyze the result.
